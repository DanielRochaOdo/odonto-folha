# Registros de decisão arquitetural

Um ADR deve incluir contexto, alternativas, trade-offs, decisão, data, estado, consequências e pessoa aprovadora. **IA não aprova ADR por conta própria.**

- `0001-fundacao-tecnica.md`: decisão candidata de arquitetura, aguardando revisão no PR.
- `0002-centros-de-custo-dinamicos.md`: centros configur\u00e1veis para atribuir comiss\u00f5es e restringir acessos.

Estados: Proposto → Aprovado → Substituído. Mudanças relevantes produzem novo ADR; não apague decisões históricas.
